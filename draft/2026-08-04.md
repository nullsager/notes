# 🧠 PyTorch Embedding 代码详解

```python
class Embedding(nn.Module):
    def __init__(self, vocab_size: int, hidden_size: int):
        super().__init__()
        # 创建一个可学习的查找表
        self.weight = nn.Parameter(torch.randn(vocab_size, hidden_size))

    def forward(self, token_ids: torch.Tensor) -> torch.Tensor:
        # token_ids: (batch_size, seq_len)
        # 返回: (batch_size, seq_len, hidden_size)
        return self.weight[token_ids]
```

---

## 1️⃣ `nn.Module` 什么情况要继承？继承了有什么用？

> [!question] 什么情况需要继承 `nn.Module`？
> 只要你想**自己定义一个神经网络层 / 网络**（有可学习参数、要被训练、要参与反向传播），就必须继承 `nn.Module`。

> [!success] 继承 `nn.Module` 的好处
> - ✅ **自动管理参数**：`self.weight = nn.Parameter(...)` 会被自动收集到 `model.parameters()`，训练时 `optimizer` 能自动拿到所有参数
> - ✅ **自动管理缓冲区**：`register_buffer` 注册的东西会跟着模型移动设备
> - ✅ **自动切换训练/评估模式**：`model.train()` / `model.eval()` 一键切换（影响 Dropout、BatchNorm 等）
> - ✅ **自动转移设备**：`model.to('cuda')` 会把所有参数和缓冲区一起搬过去
> - ✅ **继承 `forward` 机制**：调用 `model(x)` 时会自动执行 `forward(x)`（背后还有 hooks 等机制）
> - ✅ **保存与加载**：`model.state_dict()` 保存所有参数，配合 `torch.save/load` 使用

> [!example] 反例：什么时候**不需要**继承？
> 如果只是一个纯函数式的计算（比如把 `ReLU` 封装成函数、做一次矩阵乘法且没有参数），用普通函数或 `nn.functional` 就够了，不需要继承 `nn.Module`。

## 2️⃣ `super().__init__()` 是什么？`super` 什么情况用？和 `self` 有什么区别？

> [!abstract] `super().__init__()` 是什么？
> 调用**父类**（这里是 `nn.Module`）的 `__init__` 构造方法。
>
> `super()` 是 Python 的内置函数，用于获取"当前类的父类（或 MRO 中的下一个类）"的代理对象。

> [!important] 为什么必须写？
> `nn.Module` 内部维护着**参数注册表**、**模块注册表**等大量内部状态。不调用 `super().__init__()`，这些内部结构不会被初始化，之后 `self.weight = nn.Parameter(...)` 根本不会被注册，模型也无法正常工作。
>
> ⚠️ 这是 PyTorch 中**最常见的报错来源**之一：忘记写 `super().__init__()` → 模型参数丢失 → 训练不更新。

> [!note] `super` 什么情况用？
> 只要你的类**继承了一个有 `__init__` 的父类**，且你需要在子类初始化时顺带完成父类的初始化，就要用 `super().__init__()`。这在所有继承场景都适用（不限于 PyTorch）。

> [!info] `super` vs `self` 的区别
>
> | | `self` | `super()` |
> |---|---|---|
> | 指向 | 当前实例本身 | 父类的代理（通过它调用父类方法） |
> | 用途 | 访问/设置**自己的**属性和方法 | 调用**父类的**方法（如 `__init__`） |
> | 例子 | `self.weight = ...` | `super().__init__()` |

```python
class Embedding(nn.Module):
    def __init__(self, vocab_size, hidden_size):
        # super().__init__()  ← 初始化 nn.Module 的内部状态（参数注册表等）
        super().__init__()
        # self.weight = ...    ← 在自己身上挂参数，由 nn.Module 代为注册
        self.weight = nn.Parameter(torch.randn(vocab_size, hidden_size))
```

## 3️⃣ `nn.Parameter` 怎么用？只有继承了 `nn.Module` 才能用吗？

> [!abstract] `nn.Parameter` 是什么？
> `nn.Parameter` 是 `torch.Tensor` 的**子类**，它和普通 Tensor 的唯一区别是：**只要被赋值成某个 `nn.Module` 实例的属性，就会被自动注册为该模块的可学习参数**，出现在 `model.parameters()` 中，参与梯度更新。

> [!success] 用法
> ```python
> self.weight = nn.Parameter(torch.randn(vocab_size, hidden_size))
> ```
> 本质：`nn.Parameter(tensor)` 把一个普通 Tensor 包装成"参数"。
>
> 也可以通过 `nn.Parameter(data=..., requires_grad=False)` 指定是否要梯度。

> [!warning] 只有继承了 `nn.Module` 才能用吗？
> **不是**。`nn.Parameter` 本身只是 Tensor 的子类，**单独使用完全合法**，任何地方都可以创建它：
> ```python
> import torch.nn as nn
> p = nn.Parameter(torch.randn(3, 3))   # 单独创建，没问题
> ```
>
> 但是——**关键点**：只有把它**赋值给 `nn.Module` 的属性**时，它才会被自动注册、进入 `parameters()`、被优化器更新。否则它就是一个"带标记的普通 Tensor"，既不会自动进优化器，也不会自动迁移设备。
>
> 补充：
> - 直接赋值给**普通对象/列表/字典**也不会被注册（`nn.ModuleList`、`nn.ParameterDict` 等容器除外）
> - 在 `forward` 里新建的 `nn.Parameter` 也不会被注册（注册只发生在 `__init__` 期间的属性赋值，或显式 `register_parameter`）

## 4️⃣ `torch.randn` 函数怎么用？

> [!abstract] 作用
> 从**标准正态分布**（均值 μ=0，方差 σ²=1）中随机采样，生成指定形状的 Tensor。

> [!success] 基本用法
> ```python
> import torch
>
> # 传入各维度大小即可
> x = torch.randn(3)            # shape: (3,)
> y = torch.randn(2, 3)         # shape: (2, 3)
> z = torch.randn(vocab_size, hidden_size)  # 代码中的用法，二维查找表
> ```

> [!tip] 常用变体
> | 函数 | 含义 |
> |---|---|
> | `torch.randn(shape)` | 标准正态分布 N(0, 1) |
> | `torch.rand(shape)` | 均匀分布 [0, 1) |
> | `torch.randn(..., dtype=torch.float32, device='cuda')` | 指定数据类型和设备 |
> | `torch.randn_like(tensor)` | 和给定 tensor 形状相同 |
> | `torch.normal(mean, std)` | 自定义均值/方差的正态分布 |
>
> 也可以传 `torch.Size` 或列表：`torch.randn(torch.Size([2, 3]))` 或 `torch.randn([2, 3])`。

> [!info] 在代码中的作用
> 用随机值**初始化**词嵌入权重，之后在训练中通过梯度下降不断调整，学到真实的词向量表示。

## 5️⃣ `forward` 函数是什么意思？`weight` 的结构是什么？为什么 `self.weight[token_ids]` 能返回 `(batch_size, seq_len, hidden_size)`？

### 5.1 `forward` 是什么？

> [!abstract] `forward` 就是**前向传播**
> 定义"输入进来后，数据如何一步步计算得到输出"的过程。
>
> - 你写的 `forward` 定义了层的行为逻辑
> - 调用时**不要**直接写 `model.forward(x)`，而应该写 `model(x)`——`nn.Module` 的 `__call__` 会自动调用 `forward`，并顺带触发 hooks、检查设备等机制

```python
emb = Embedding(vocab_size=1000, hidden_size=64)
out = emb(torch.tensor([[1, 2, 3]]))   # ✅ 推荐写法，等价于 emb.forward(...)
```

### 5.2 `weight` 的结构

> [!info] `weight` 是一个形状为 `(vocab_size, hidden_size)` 的二维 Tensor
>
> | 维度 | 含义 | 举例 |
> |---|---|---|
> | 第 0 维 `vocab_size` | 词表大小 = 一共有多少个不同的词 | 1000 |
> | 第 1 维 `hidden_size` | 每个词被表示成多少维的向量 | 64 |
>
> 这就是一张 **查找表（Lookup Table）**：
> - 第 `i` 行 = 词表里第 `i` 个词的向量表示
> - 比如 `weight[5]` 就是"词 id 为 5 的词向量"，形状 `(hidden_size,)`

### 5.3 为什么 `self.weight[token_ids]` 返回 `(batch_size, seq_len, hidden_size)`？

> [!success] 核心原理：**Tensor 高级索引（按整数数组取下标）**
>
> 当用 **Tensor 作为索引** 时，PyTorch 会为索引张量里的**每一个位置**，取出一行，并且**保留索引张量的形状**。

```python
# weight: (vocab_size, hidden_size)
# token_ids: (batch_size, seq_len)，每个位置是一个词 id
result = self.weight[token_ids]
# result: (batch_size, seq_len, hidden_size)
```

**逐步拆解：**

1. `token_ids` 有 `batch_size × seq_len` 个位置
2. 对**每个位置** `(b, s)`，取出 `weight[token_ids[b, s]]`，它是一个长度为 `hidden_size` 的词向量
3. 所有位置的结果按原位置排列，就得到了 `(batch_size, seq_len, hidden_size)`

```python
import torch

weight = torch.randn(4, 3)   # vocab_size=4, hidden_size=3
token_ids = torch.tensor([[0, 1], [2, 3]])   # batch_size=2, seq_len=2

out = weight[token_ids]
print(out.shape)   # torch.Size([2, 2, 3])  ← (batch, seq, hidden)

# 验证：out[0, 0] 应该等于 weight[0]
print(torch.equal(out[0, 0], weight[0]))   # True
```

> [!example] 生活中的类比
> `weight` 像一本"词典"（`vocab_size` 页，每页 `hidden_size` 个字）；`token_ids` 是一张写着页码的表格（`batch_size` 行 × `seq_len` 列）。按页码查词 → 翻到那一页，把整页内容抄回表格的对应位置 → 表格每个格子从"一个页码"变成了"一整页内容"，于是形状多了最后一维 `hidden_size`。

## 📌 总结速查

> [!success] 一句话总结
> - **继承 `nn.Module`** → 拿到参数自动管理、设备迁移、train/eval 切换等全套能力
> - **`super().__init__()`** → 初始化父类内部机制，**必写**
> - **`nn.Parameter`** → 带"可学习"标记的 Tensor，挂到 Module 属性上即自动注册
> - **`torch.randn`** → 标准正态分布随机初始化
> - **`forward`** → 前向传播逻辑；`weight` 是 `(vocab_size, hidden_size)` 查找表；`weight[token_ids]` 用高级索引把每个词 id 替换成对应词向量，得到 `(batch, seq, hidden)`

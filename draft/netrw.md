# netrw 文件管理器详解

> [!info] 什么是 netrw？
> **netrw** 是 Vim/Neovim 自带的文件管理器，无需安装任何插件即可使用。它以 `Netrw Directory Listing` 的方式浏览文件系统，支持**树形目录**、**水平/垂直分割**打开、**重命名/删除/复制**文件等功能。
> 本文基于你在 `init.lua` 中的个性化配置编写。

---

## 1. 快速开始

### 1.1 几种打开方式

| 命令 | 作用 |
| --- | --- |
| `:Explore` / `:E` | 在当前窗口打开文件管理器 |
| `:Lexplore` / `:Lexplore` | 在**左侧**垂直分割打开（面板式） |
| `:Rexplore` / `:Rexplore` | 在右侧打开 |
| `:Sexplore` | 水平分割打开 |
| `:Vexplore` | 垂直分割打开 |
| `:NetrwSettings` | 打开 netrw 帮助 / 设置页面 |

### 1.2 你的专属快捷键

> [!tip] 来自你的 `init.lua`
> 你的配置里有两条与 netrw 高度相关的快捷键，都用空格作为 `<Leader>`：

| 快捷键 | 作用 |
| --- | --- |
| `<leader>e` | 切换（打开/关闭）左侧 netrw 文件树面板 |
| `<leader>oo` | 直接打开整个 Obsidian 笔记库目录，进入后所有 Obsidian 命令照常可用 |

```lua
-- 对应配置片段
vim.g.mapleader = " "

vim.keymap.set('n', '<leader>e', '<Cmd>Lexplore<CR>', { desc = "Toggle Netrw" })
vim.keymap.set("n", "<leader>oo", function()
  vim.cmd.edit(notes_path)  -- notes_path = "/home/lc/Documents/notes"
end, { desc = "Browse Obsidian vault" })
```

## 2. 界面构成

当你输入 `:Lexplore` 后，屏幕上会出现大概这样的界面（因为你设置了 `netrw_banner = 0`，顶部的帮助横幅是隐藏的）：

```
┌ ./                                        ← 当前目录
│ ⨯ ..                                      ← 父目录
│ ⨯ .git
│ ⨯ draft
│ ⨯ [[netrw.md]]                            ← 当前正在编辑的文件
│ ⨯ [[obsidian neovim.md]]
│ ⨯ ag/                                     ← 目录（带 / 结尾）
│ ⨯ lsp/
│ ...
```

> [!note] 符号含义
> - 名称带 `/` 的是**目录**，不带 `/` 的是**文件**。
> - `..` 表示**父目录**，`./` 表示**当前目录本身**。
> - 点击目录名可以**展开/折叠**子目录（树形视图），点击文件会按你的规则打开它。

## 3. 核心操作（模式对照）

> [!important] netrw 的操作都在**普通模式（Normal mode）**下进行，光标停在想操作的项目上，直接按字母即可。

### 3.1 浏览与打开文件

| 按键 | 功能 |
| --- | --- |
| `o` | 在**当前窗口**打开文件/进入目录 |
| `v` | 在**垂直分割**窗口中打开（右侧） |
| `s` | 在**水平分割**窗口中打开（下方） |
| `P` | 在**预览窗口**打开文件 |
| `t` | 在新标签页中打开 |
| `C` | 改变 netrw 的根目录为当前光标所在目录 |
| `<CR>` / `Enter` | 打开文件（行为由 `netrw_browse_split` 决定） |

> [!tip] 你的配置：树形结构 + 右侧打开
> ```lua
> vim.g.netrw_liststyle = 3      -- 树形视图：在目录上按回车可展开/收起
> vim.g.netrw_browse_split = 4   -- 按回车打开文件时，在"上一个窗口"打开
> vim.g.netrw_altv = 1           -- 分割时新窗口放在右边
> ```
> 所以在这个文件树中，`Enter` 展开目录树；按 `v` 或直接回车打开文件时文件会出现在**右侧**窗口。

**浏览历史 / 跳转：**
- `u`：跳转到历史访问过的更深一层目录（相当于浏览器"后退"）
- `U`：跳转到历史更浅一层目录（"前进"）
- `T`：回到整体最顶层的根目录

### 3.2 新建与编辑

| 按键 | 功能 |
| --- | --- |
| `%` | **新建文件**（输入文件名，注意要写扩展名如 `.md`） |
| `d` | **新建目录** |
| `R` | 将光标所在文件/目录设为当前/根目录 |
| `E` | 在 netrw 里就地编辑某个文件（会替换当前为编辑器） |
| `ma` | 设置当前文件所在目录为 netrw 的"主目录" |
| `D` | **删除**光标下的文件/目录（会弹出确认） |

### 3.3 标记与批量操作

netrw 支持用 `mt`、`mf`、`m` 系列命令批量操作：

| 按键 | 功能 |
| --- | --- |
| `mt` | 设置**目标标记**（想移动/复制到的目录） |
| `mf` | 标记光标下的文件/目录（可标记多个） |
| `mm` | **移动**已标记的文件到目标目录 |
| `mc` | **复制**已标记的文件到目标目录 |
| `md` | 对已标记的文件应用 `diff` 比较 |
| `mL` | 为标记的文件"改小写文件名"（部分老版本） |
| `mb` | 将标记的文件设为书签 |
| `mb` + `mb` | （在另一处）跳转到书签目录 |
| `mv` | 不常用，快速跳转到一个目录 |
| `mr` | 反向：把标记目标/查看关系反过来 |

> [!example] 批量移动文件三步走
> 1. 先 `cd` 或用 `vc` 进入目标目录，按 `mt` 把它设为目标。
> 2. 回到来源目录，在文件上按 `mf` 逐个标记（会有 `> ` 前缀提示）。
> 3. 按 `mm` 完成移动，按 `mc` 则变成复制。

### 3.4 显示与刷新

| 按键 | 功能 |
| --- | --- |
| `I` | 切换显示/隐藏顶部的帮助横幅（你全局关闭了它，此键可临时呼出） |
| `r` | 反转排序方向（升序 ↔ 降序） |
| `s` | 修改排序依据（按名字/时间/大小等，可循环切换） |
| `p` | 预览文件内容（如果可用） |
| `x` | 用**外部默认程序**打开文件（配合 `netrw_browsex_viewer`） |
| `X` | 关闭/撤销 netrw |

### 3.5 其他实用按键

| 按键 | 功能 |
| --- | --- |
| `-` | 跳到**父目录** |
| `..` | 返回上一级 |
| `~` | 跳到用户主目录 `$HOME` |
| `c` | 修改当前目录（输入新路径） |
| `cd` | 让当前目录成为 netrw 的根 |
| `y` / `Y` | 复制当前路径（较新版本支持 `y`） |
| `gx` | 用浏览器打开当前 URL/路径 |
| `<F5>` | 强制刷新目录列表 |
| `Ctrl+L` | 刷新当前目录 |

## 5. 实战流程

> [!success] 常用场景一：用 `<leader>e` 浏览整个笔记库
> 1. 按 `<leader>e` 打开左侧文件树。
> 2. 在目录上按 `Enter` 展开/折叠子目录。
> 3. 在文件上按 `v` 在右侧垂直窗口打开（推荐搭配笔记阅读）。
> 4. 再按一次 `<leader>e` 即可关闭面板。

> [!success] 常用场景二：用 `<leader>oo` 打开整个 Obsidian 库
> 1. 按 `<leader>oo` 直接在 netrw 中看到 `notes` 根目录。
> 2. `+` 展开章节目录，找到目标 `.md` 文件进入编辑。
> 3. 进入后所有 Obsidian 命令（如 `<leader>os` 搜索、`<leader>ob` backlinks）依旧生效。

## 6. 相关全局设置速览

你自己的 `init.lua` 里还设置了这些通用项（影响所有 netrw 使用）：

```lua
vim.g.netrw_winsize = 20     -- 面板宽度占屏幕的 20%
vim.g.netrw_liststyle = 3    -- 树形目录显示
vim.g.netrw_banner = 0       -- 不显示顶部帮助横幅
vim.g.netrw_browse_split = 4 -- 回车在"上一个窗口"打开文件
vim.g.netrw_altv = 1         -- 垂直分割放在右侧
```

若要临时调整，可用 `:let g:netrw_xxx = value` 后 `:e .` 刷新生效。

## 7. 小结

| 目的 | 最快路径 |
| --- | --- |
| 打开文件树 | `<leader>e` |
| 打开笔记库 | `<leader>oo` |
| 展开目录 | 目录上按 `Enter` |
| 在右侧打开文件 | `v` |
| 新建文件 | `%` |
| 新建目录 | `d` |
| 重命名 | `R` |
| 删除 | `D` |
| 跳到父目录 | `-` |
| 呼出帮助横幅 | `I` |

> [!quote] 
> netrw 的强大之处在于"零依赖、随处可用"——即使将来换机器、不装任何文件树插件，`netrw` 依然能让你高效地完成文件管理。

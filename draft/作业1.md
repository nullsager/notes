# 法律问答 RAG 作业实现方案

下面给出一套可直接运行的实现，技术路线如下：

- 法律数据：以《中华人民共和国劳动合同法》为例
- 文本切分：正则表达式按“第一条、第二条……”切分
- Embedding：`BAAI/bge-large-zh-v1.5`
- 向量数据库：Milvus
- 向量召回：Top-10
- 精排模型：`jinaai/jina-reranker-v2-base-multilingual`
- 精排结果：Top-3
- 本地大模型：通过 Ollama 调用，例如 `qwen3:8b`
- 对比实验：相同模型、温度、随机种子和最大输出长度，分别执行无 RAG 和有 RAG

# 三、法律文本预处理

需要注意两个问题：

1. 法条正文可能跨越多行。
2. “第一章”“第一节”等标题不能错误地附加到上一条法条。

下面的程序会：

- 统一换行符；
- 删除单独成行的编、章、节标题；
- 识别“第十九条”“第七十条之一”等编号；
- 每条法条保存为一条 JSONL 数据。

<details open>
<summary><strong>preprocess.py</strong></summary>

```python
import argparse
import json
import re
from pathlib import Path


ARTICLE_PATTERN = re.compile(
    r"(?m)^[ \t]*"
    r"(第[零〇一二三四五六七八九十百千万两\d]+条"
    r"(?:之[零〇一二三四五六七八九十百千万两\d]+)?)"
    r"[ \t]*"
)

HEADING_PATTERN = re.compile(
    r"(?m)^[ \t]*"
    r"第[零〇一二三四五六七八九十百千万两\d]+"
    r"[编章节]"
    r"[^\n]*$"
)


def normalize_text(text: str) -> str:
    """统一格式并清除章、节等标题。"""
    text = text.replace("\r\n", "\n").replace("\r", "\n")
    text = text.replace("\u3000", " ")
    text = HEADING_PATTERN.sub("", text)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text.strip()


def clean_article_body(body: str) -> str:
    """将一条法条内部的多行正文整理为连续文本。"""
    lines = []

    for line in body.splitlines():
        line = line.strip()
        if line:
            lines.append(line)

    body = "\n".join(lines)
    body = re.sub(r"[ \t]+", " ", body)
    return body.strip()


def split_law(text: str, law_name: str) -> list[dict]:
    """按照法条编号切分法律文本。"""
    text = normalize_text(text)
    matches = list(ARTICLE_PATTERN.finditer(text))

    if not matches:
        raise ValueError("没有识别到法条，请检查文本格式或正则表达式。")

    articles = []

    for index, match in enumerate(matches):
        article_no = match.group(1)

        body_start = match.end()
        body_end = (
            matches[index + 1].start()
            if index + 1 < len(matches)
            else len(text)
        )

        article_body = clean_article_body(text[body_start:body_end])

        if not article_body:
            continue

        articles.append(
            {
                "law_name": law_name,
                "article_no": article_no,
                "article_text": article_body,
                "full_text": f"《{law_name}》{article_no} {article_body}",
            }
        )

    return articles


def process_file(input_path: Path, output_path: Path, law_name: str):
    text = input_path.read_text(encoding="utf-8")
    articles = split_law(text, law_name)

    output_path.parent.mkdir(parents=True, exist_ok=True)

    with output_path.open("w", encoding="utf-8") as file:
        for article in articles:
            file.write(
                json.dumps(article, ensure_ascii=False) + "\n"
            )

    print(f"法律名称：{law_name}")
    print(f"识别法条数量：{len(articles)}")
    print(f"输出文件：{output_path}")

    print("\n前 3 条切分结果：")
    for article in articles[:3]:
        print("-" * 80)
        print(article["full_text"])


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--input",
        default="data/raw/中华人民共和国劳动合同法.txt",
    )
    parser.add_argument(
        "--output",
        default="data/processed/laws.jsonl",
    )
    parser.add_argument(
        "--law-name",
        default="中华人民共和国劳动合同法",
    )
    args = parser.parse_args()

    process_file(
        input_path=Path(args.input),
        output_path=Path(args.output),
        law_name=args.law_name,
    )
```

# 四、构建 Milvus 向量知识库

`bge-large-zh-v1.5` 的向量维度为 $1024$。程序对向量进行归一化，并在 Milvus 中使用余弦相似度。

写入字段包括：

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | INT64 | 自动生成的主键 |
| `embedding` | FLOAT_VECTOR | 法条向量 |
| `law_name` | VARCHAR | 法律名称 |
| `article_no` | VARCHAR | 法条编号 |
| `article_text` | VARCHAR | 法条正文 |

<details open>
<summary><strong>build_milvus.py</strong></summary>

```python
import argparse
import json
from pathlib import Path

from pymilvus import DataType, MilvusClient
from sentence_transformers import SentenceTransformer


DEFAULT_MODEL = "BAAI/bge-large-zh-v1.5"
DEFAULT_COLLECTION = "legal_articles"
EMBEDDING_DIM = 1024


def load_articles(path: Path) -> list[dict]:
    articles = []

    with path.open("r", encoding="utf-8") as file:
        for line in file:
            line = line.strip()
            if line:
                articles.append(json.loads(line))

    return articles


def create_collection(
    client: MilvusClient,
    collection_name: str,
):
    if client.has_collection(collection_name):
        client.drop_collection(collection_name)
        print(f"已删除旧 Collection：{collection_name}")

    schema = client.create_schema(
        auto_id=True,
        enable_dynamic_field=False,
    )

    schema.add_field(
        field_name="id",
        datatype=DataType.INT64,
        is_primary=True,
    )
    schema.add_field(
        field_name="embedding",
        datatype=DataType.FLOAT_VECTOR,
        dim=EMBEDDING_DIM,
    )
    schema.add_field(
        field_name="law_name",
        datatype=DataType.VARCHAR,
        max_length=512,
    )
    schema.add_field(
        field_name="article_no",
        datatype=DataType.VARCHAR,
        max_length=128,
    )
    schema.add_field(
        field_name="article_text",
        datatype=DataType.VARCHAR,
        max_length=16384,
    )

    index_params = client.prepare_index_params()
    index_params.add_index(
        field_name="embedding",
        index_type="AUTOINDEX",
        metric_type="COSINE",
    )

    client.create_collection(
        collection_name=collection_name,
        schema=schema,
        index_params=index_params,
    )

    print(f"Collection 创建完成：{collection_name}")


def build_database(
    jsonl_path: Path,
    milvus_uri: str,
    collection_name: str,
    model_name: str,
    device: str | None,
):
    articles = load_articles(jsonl_path)
    print(f"读取法条数量：{len(articles)}")

    model = SentenceTransformer(
        model_name,
        device=device,
    )

    # 法条属于 passage，不添加查询指令。
    passage_texts = [
        article["full_text"]
        for article in articles
    ]

    embeddings = model.encode(
        passage_texts,
        batch_size=16,
        normalize_embeddings=True,
        show_progress_bar=True,
    )

    client = MilvusClient(uri=milvus_uri)
    create_collection(client, collection_name)

    rows = []

    for article, embedding in zip(articles, embeddings):
        rows.append(
            {
                "embedding": embedding.tolist(),
                "law_name": article["law_name"],
                "article_no": article["article_no"],
                "article_text": article["article_text"],
            }
        )

    batch_size = 100

    for start in range(0, len(rows), batch_size):
        batch = rows[start:start + batch_size]
        result = client.insert(
            collection_name=collection_name,
            data=batch,
        )
        print(f"已写入：{result['insert_count']} 条")

    client.flush(collection_name)
    client.load_collection(collection_name)

    stats = client.get_collection_stats(collection_name)
    print("Milvus 数据库构建完成。")
    print(f"Collection 统计信息：{stats}")


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--input",
        default="data/processed/laws.jsonl",
    )
    parser.add_argument(
        "--milvus-uri",
        default="./data/milvus.db",
    )
    parser.add_argument(
        "--collection",
        default=DEFAULT_COLLECTION,
    )
    parser.add_argument(
        "--model",
        default=DEFAULT_MODEL,
    )
    parser.add_argument(
        "--device",
        default=None,
        help="例如 cuda、cuda:0 或 cpu",
    )
    args = parser.parse_args()

    build_database(
        jsonl_path=Path(args.input),
        milvus_uri=args.milvus_uri,
        collection_name=args.collection,
        model_name=args.model,
        device=args.device,
    )
```

# 五、实现 Top-10 召回与 Top-3 精排

BGE 官方建议：短查询检索长文档时，可以给查询添加检索指令，但文档不添加指令。

查询向量化使用：

```text
为这个句子生成表示以用于检索相关文章：用户问题
```

精排模型直接计算“用户问题—候选法条”的相关性得分，得分越高，相关性越高。

同时通过 Ollama 调用本地大模型。先安装 Ollama，然后下载模型：

```bash
ollama pull qwen3:8b
```

启动 Ollama：

```bash
ollama serve
```

<details open>
<summary><strong>rag_system.py</strong></summary>

```python
import argparse
from dataclasses import asdict, dataclass

import requests
import torch
from pymilvus import MilvusClient
from sentence_transformers import SentenceTransformer
from transformers import AutoModelForSequenceClassification


EMBEDDING_MODEL_NAME = "BAAI/bge-large-zh-v1.5"
RERANKER_MODEL_NAME = (
    "jinaai/jina-reranker-v2-base-multilingual"
)
QUERY_INSTRUCTION = "为这个句子生成表示以用于检索相关文章："


@dataclass
class RetrievedArticle:
    law_name: str
    article_no: str
    article_text: str
    recall_score: float
    reranker_score: float = 0.0

    @property
    def full_text(self) -> str:
        return (
            f"《{self.law_name}》"
            f"{self.article_no} {self.article_text}"
        )


class LegalRAG:
    def __init__(
        self,
        milvus_uri: str = "./data/milvus.db",
        collection_name: str = "legal_articles",
        embedding_device: str | None = None,
        reranker_device: str | None = None,
        ollama_url: str = "http://localhost:11434",
        llm_model: str = "qwen3:8b",
    ):
        self.collection_name = collection_name
        self.client = MilvusClient(uri=milvus_uri)
        self.client.load_collection(collection_name)

        self.embedding_model = SentenceTransformer(
            EMBEDDING_MODEL_NAME,
            device=embedding_device,
        )

        if reranker_device is None:
            reranker_device = (
                "cuda" if torch.cuda.is_available() else "cpu"
            )

        self.reranker_device = reranker_device

        self.reranker = (
            AutoModelForSequenceClassification.from_pretrained(
                RERANKER_MODEL_NAME,
                torch_dtype="auto",
                trust_remote_code=True,
                use_flash_attn=False,
            )
        )
        self.reranker.to(reranker_device)
        self.reranker.eval()

        self.ollama_url = ollama_url.rstrip("/")
        self.llm_model = llm_model

    def recall(
        self,
        question: str,
        top_k: int = 10,
    ) -> list[RetrievedArticle]:
        query_text = QUERY_INSTRUCTION + question

        query_vector = self.embedding_model.encode(
            [query_text],
            normalize_embeddings=True,
        )[0].tolist()

        search_results = self.client.search(
            collection_name=self.collection_name,
            data=[query_vector],
            anns_field="embedding",
            limit=top_k,
            search_params={
                "metric_type": "COSINE",
                "params": {},
            },
            output_fields=[
                "law_name",
                "article_no",
                "article_text",
            ],
        )

        candidates = []

        for hit in search_results[0]:
            entity = hit["entity"]

            candidates.append(
                RetrievedArticle(
                    law_name=entity["law_name"],
                    article_no=entity["article_no"],
                    article_text=entity["article_text"],
                    recall_score=float(hit["distance"]),
                )
            )

        return candidates

    def rerank(
        self,
        question: str,
        candidates: list[RetrievedArticle],
        top_k: int = 3,
    ) -> list[RetrievedArticle]:
        if not candidates:
            return []

        sentence_pairs = [
            [question, candidate.full_text]
            for candidate in candidates
        ]

        with torch.no_grad():
            scores = self.reranker.compute_score(
                sentence_pairs,
                max_length=1024,
            )

        if not isinstance(scores, list):
            scores = [scores]

        for candidate, score in zip(candidates, scores):
            candidate.reranker_score = float(score)

        candidates.sort(
            key=lambda item: item.reranker_score,
            reverse=True,
        )

        return candidates[:top_k]

    def retrieve(
        self,
        question: str,
        recall_top_k: int = 10,
        final_top_k: int = 3,
    ) -> tuple[list[RetrievedArticle], list[RetrievedArticle]]:
        recalled = self.recall(
            question=question,
            top_k=recall_top_k,
        )

        reranked = self.rerank(
            question=question,
            candidates=recalled,
            top_k=final_top_k,
        )

        return recalled, reranked

    @staticmethod
    def build_prompt(
        question: str,
        articles: list[RetrievedArticle] | None,
    ) -> str:
        common_instruction = """
你是一名法律问答助手。请直接回答用户问题。

回答要求：
1. 使用中文；
2. 先给出明确结论，再说明理由；
3. 不得虚构法律名称、法条编号或案件事实；
4. 如果信息不足，应明确说明需要补充哪些事实；
5. 回答只用于一般性法律信息参考，不替代专业法律意见。
""".strip()

        if not articles:
            return (
                f"{common_instruction}\n\n"
                f"用户问题：\n{question}"
            )

        context_parts = []

        for index, article in enumerate(articles, start=1):
            context_parts.append(
                f"参考法条 {index}：\n{article.full_text}"
            )

        context = "\n\n".join(context_parts)

        rag_instruction = """
请优先依据下列参考法条回答。引用时应明确写出法律名称和法条编号。
如果参考法条不能完整支持答案，不要自行编造缺失规定，应说明依据不足。
""".strip()

        return (
            f"{common_instruction}\n\n"
            f"{rag_instruction}\n\n"
            f"{context}\n\n"
            f"用户问题：\n{question}"
        )

    def generate(
        self,
        prompt: str,
        temperature: float = 0.1,
        max_tokens: int = 512,
        seed: int = 42,
    ) -> str:
        response = requests.post(
            f"{self.ollama_url}/api/generate",
            json={
                "model": self.llm_model,
                "prompt": prompt,
                "stream": False,
                "options": {
                    "temperature": temperature,
                    "num_predict": max_tokens,
                    "seed": seed,
                    "top_p": 0.9,
                },
            },
            timeout=600,
        )
        response.raise_for_status()
        return response.json()["response"].strip()

    def answer_without_rag(
        self,
        question: str,
        temperature: float = 0.1,
        max_tokens: int = 512,
        seed: int = 42,
    ) -> str:
        prompt = self.build_prompt(
            question=question,
            articles=None,
        )

        return self.generate(
            prompt=prompt,
            temperature=temperature,
            max_tokens=max_tokens,
            seed=seed,
        )

    def answer_with_rag(
        self,
        question: str,
        temperature: float = 0.1,
        max_tokens: int = 512,
        seed: int = 42,
    ) -> dict:
        recalled, top_articles = self.retrieve(question)

        prompt = self.build_prompt(
            question=question,
            articles=top_articles,
        )

        answer = self.generate(
            prompt=prompt,
            temperature=temperature,
            max_tokens=max_tokens,
            seed=seed,
        )

        return {
            "question": question,
            "recalled_top10": [
                asdict(item) for item in recalled
            ],
            "reranked_top3": [
                asdict(item) for item in top_articles
            ],
            "answer": answer,
        }


def print_retrieval_results(
    recalled: list[RetrievedArticle],
    reranked: list[RetrievedArticle],
):
    print("\n========== Milvus Top-10 ==========")

    for index, item in enumerate(recalled, start=1):
        print(
            f"{index}. 《{item.law_name}》{item.article_no} "
            f"召回分数={item.recall_score:.6f}"
        )

    print("\n========== Reranker Top-3 ==========")

    for index, item in enumerate(reranked, start=1):
        print(
            f"{index}. 《{item.law_name}》{item.article_no} "
            f"召回分数={item.recall_score:.6f} "
            f"精排分数={item.reranker_score:.6f}"
        )
        print(item.article_text)
        print()


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("question")
    parser.add_argument(
        "--milvus-uri",
        default="./data/milvus.db",
    )
    parser.add_argument(
        "--collection",
        default="legal_articles",
    )
    parser.add_argument(
        "--llm-model",
        default="qwen3:8b",
    )
    parser.add_argument(
        "--embedding-device",
        default=None,
    )
    parser.add_argument(
        "--reranker-device",
        default=None,
    )
    args = parser.parse_args()

    rag = LegalRAG(
        milvus_uri=args.milvus_uri,
        collection_name=args.collection,
        embedding_device=args.embedding_device,
        reranker_device=args.reranker_device,
        llm_model=args.llm_model,
    )

    recalled, reranked = rag.retrieve(args.question)
    print_retrieval_results(recalled, reranked)

    print("\n========== 无 RAG 回答 ==========")
    print(
        rag.answer_without_rag(
            args.question,
            temperature=0.1,
            max_tokens=512,
            seed=42,
        )
    )

    print("\n========== 有 RAG 回答 ==========")

    rag_result = rag.answer_with_rag(
        args.question,
        temperature=0.1,
        max_tokens=512,
        seed=42,
    )
    print(rag_result["answer"])
```

# 六、有 RAG 与无 RAG 对比实验

选择以下三个问题：

1. 劳动合同期限为一年，试用期最长可以约定多久？
2. 入职三个月了，公司一直没有和我签书面劳动合同，公司需要承担什么责任？
3. 劳动者正常辞职需要提前多少天通知公司？试用期内又需要提前多少天？

预期关键法条分别为：

| 案例 | 预期关键法条 |
|---|---|
| 试用期长度 | 《劳动合同法》第十九条 |
| 未签书面劳动合同 | 《劳动合同法》第十条、第八十二条 |
| 劳动者提前辞职 | 《劳动合同法》第三十七条 |

<details open>
<summary><strong>experiment.py</strong></summary>

```python
import json
import time
from pathlib import Path

from rag_system import LegalRAG


QUESTIONS = [
    "劳动合同期限为一年，试用期最长可以约定多久？",
    "入职三个月了，公司一直没有和我签书面劳动合同，公司需要承担什么责任？",
    "劳动者正常辞职需要提前多少天通知公司？试用期内又需要提前多少天？",
]

GENERATION_CONFIG = {
    "temperature": 0.1,
    "max_tokens": 512,
    "seed": 42,
}


def run_experiment():
    rag = LegalRAG(
        milvus_uri="./data/milvus.db",
        collection_name="legal_articles",
        embedding_device=None,
        reranker_device=None,
        llm_model="qwen3:8b",
    )

    results = []

    for case_id, question in enumerate(QUESTIONS, start=1):
        print("=" * 100)
        print(f"案例 {case_id}：{question}")

        no_rag_start = time.perf_counter()
        no_rag_answer = rag.answer_without_rag(
            question=question,
            **GENERATION_CONFIG,
        )
        no_rag_seconds = time.perf_counter() - no_rag_start

        rag_start = time.perf_counter()
        rag_result = rag.answer_with_rag(
            question=question,
            **GENERATION_CONFIG,
        )
        rag_seconds = time.perf_counter() - rag_start

        case_result = {
            "case_id": case_id,
            "question": question,
            "generation_config": GENERATION_CONFIG,
            "model": rag.llm_model,
            "without_rag": {
                "answer": no_rag_answer,
                "elapsed_seconds": round(no_rag_seconds, 4),
            },
            "with_rag": {
                "answer": rag_result["answer"],
                "elapsed_seconds": round(rag_seconds, 4),
                "recalled_top10": rag_result[
                    "recalled_top10"
                ],
                "reranked_top3": rag_result[
                    "reranked_top3"
                ],
            },
        }

        results.append(case_result)

        print("\n【无 RAG】")
        print(no_rag_answer)

        print("\n【Reranker Top-3】")
        for index, article in enumerate(
            rag_result["reranked_top3"],
            start=1,
        ):
            print(
                f"{index}. "
                f"《{article['law_name']}》"
                f"{article['article_no']} "
                f"精排得分："
                f"{article['reranker_score']:.6f}"
            )

        print("\n【有 RAG】")
        print(rag_result["answer"])

    output_path = Path("results/experiment_results.json")
    output_path.parent.mkdir(parents=True, exist_ok=True)

    output_path.write_text(
        json.dumps(
            results,
            ensure_ascii=False,
            indent=2,
        ),
        encoding="utf-8",
    )

    print(f"\n实验结果已保存到：{output_path}")


if __name__ == "__main__":
    run_experiment()
```

执行实验：

```bash
python experiment.py
```

# 七、实验报告写法

不能在没有实际运行模型的情况下虚构模型输出。因此，应当运行 `experiment.py`，将真实结果复制到报告中。

## 1. 实验参数

| 参数 | 设置 |
|---|---|
| 本地大语言模型 | `qwen3:8b` |
| Embedding 模型 | `BAAI/bge-large-zh-v1.5` |
| Reranker 模型 | `jinaai/jina-reranker-v2-base-multilingual` |
| Milvus 召回数量 | Top-10 |
| Reranker 输出数量 | Top-3 |
| Temperature | `0.1` |
| 最大生成长度 | `512` |
| Random seed | `42` |
| Top-p | `0.9` |

两组实验只有输入上下文不同：

- 无 RAG：公共回答指令和用户问题；
- 有 RAG：相同公共回答指令、用户问题以及 Top-3 法条。

两组没有改变模型和生成参数，因此具有可比性。

## 2. 结果记录表

| 案例 | 无 RAG 法律结论是否正确 | 有 RAG 法律结论是否正确 | Top-10 是否命中关键法条 | Top-3 是否命中关键法条 | 引用是否准确 |
|---|---:|---:|---:|---:|---:|
| 案例一 | 运行后填写 | 运行后填写 | 运行后填写 | 运行后填写 | 运行后填写 |
| 案例二 | 运行后填写 | 运行后填写 | 运行后填写 | 运行后填写 | 运行后填写 |
| 案例三 | 运行后填写 | 运行后填写 | 运行后填写 | 运行后填写 | 运行后填写 |

可以使用以下人工评分标准：

- 法律结论正确：$1$ 分，否则 $0$ 分；
- 法条编号正确：$1$ 分，否则 $0$ 分；
- 法律理由完整：$1$ 分，否则 $0$ 分；
- 没有虚构内容：$1$ 分，否则 $0$ 分。

每个回答最高 $4$ 分。

## 3. 预期标准答案

### 案例一

劳动合同期限为一年，试用期最长不得超过两个月。关键依据是《中华人民共和国劳动合同法》第十九条。

### 案例二

用人单位自用工之日起超过一个月、不满一年仍未签订书面劳动合同，应当向劳动者每月支付二倍工资。关键依据包括《中华人民共和国劳动合同法》第十条和第八十二条。

具体工资计算期间、仲裁时效和证据情况需要结合实际案情判断。

### 案例三

一般情况下，劳动者提前三十日以书面形式通知用人单位，可以解除劳动合同；在试用期内，提前三日通知用人单位即可。关键依据是《中华人民共和国劳动合同法》第三十七条。

# 八、可直接放入报告的实验分析

> 本实验以《中华人民共和国劳动合同法》作为法律知识库数据，首先通过正则表达式识别“第一条、第二条”等法条编号，将原始法律文本切分为法条级文本片段。每条数据包含法律名称、法条编号和法条正文。
>
> 随后，实验使用 `BAAI/bge-large-zh-v1.5` 对法条进行向量化，并将 $1024$ 维文本向量及其元数据写入 Milvus。对于用户问题，系统首先生成查询向量，通过余弦相似度在 Milvus 中召回 Top-10 候选法条，再使用 `jinaai/jina-reranker-v2-base-multilingual` 计算问题与候选法条之间的相关性，将候选结果重新排序并选出 Top-3。
>
> 在生成阶段，有 RAG 和无 RAG 两组实验均使用相同的本地大语言模型、温度、最大输出长度、Top-p 和随机种子。无 RAG 组只提供回答指令和用户问题；有 RAG 组额外提供检索并精排后的 Top-3 法条。
>
> 对比结果主要考察法律结论是否正确、关键法条是否被命中、法条引用是否准确，以及模型是否产生虚构内容。通常情况下，无 RAG 模型能够回答部分常见法律问题，但可能遗漏适用条件、引用错误法条编号，或者使用不够准确的表述。有 RAG 模型可以直接依据检索出的法律原文回答，在法条编号准确性、回答可解释性和事实依据方面通常表现更好。
>
> 实验也表明，RAG 的最终效果依赖检索质量。如果关键法条没有进入 Top-10，Reranker 无法恢复该法条；如果 Top-3 中存在语义相关但并不直接适用的法条，大模型也可能错误引用。因此，实际系统中还可以增加关键词检索、法律名称过滤、法条关联扩展和引用一致性检查等机制。

# 九、运行顺序

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 下载本地大模型
ollama pull qwen3:8b

# 3. 启动本地模型服务
ollama serve

# 4. 切分法律文本
python preprocess.py

# 5. 构建 Milvus 向量知识库
python build_milvus.py --device cuda

# 6. 测试单个问题
python rag_system.py \
  "劳动合同期限为一年，试用期最长可以约定多久？" \
  --embedding-device cuda \
  --reranker-device cuda

# 7. 运行三个对比实验
python experiment.py
```

如果显存不足，可以将 Embedding 和 Reranker 放在 CPU：

```bash
python rag_system.py \
  "劳动者辞职需要提前多少天通知公司？" \
  --embedding-device cpu \
  --reranker-device cpu
```

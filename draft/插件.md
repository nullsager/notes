下面是这个插件的完整使用说明。它的核心用途是：**收藏网页中的单词或短语，并在之后浏览网页时自动高亮显示。**

---

# 一、安装插件

这是一个本地开发版 Chrome 插件，需要手动加载。

1. 在 Chrome 地址栏打开：

   ```text
   chrome://extensions/
   ```

2. 打开右上角的 **“开发者模式”**。

3. 点击 **“加载已解压的扩展程序”**。

4. 选择插件目录：

   ```text
   /home/lc/Projects/chrome-vocab-notebook
   ```

5. 安装完成后，建议点击浏览器工具栏右侧的“扩展程序”图标，将 **WordBook - 生词本** 固定到工具栏。

如果之前已经安装过旧版本：

1. 在 `chrome://extensions/` 找到 WordBook。
2. 点击 **“重新加载”**。
3. 刷新之前已经打开的网页。

> 扩展重新加载后，旧网页里的内容脚本不会自动更新，因此需要手动刷新网页。

---

# 二、收藏网页中的单词

插件提供四种收藏方式。

## 方法 1：网页划词快速收藏

这是最方便的方式。

1. 在普通网页中，用鼠标选中一个单词或短语。
2. 松开鼠标后，选中文字附近会出现：

   ```text
   📖 收藏
   ```

3. 点击按钮。
4. 按钮显示“收藏成功”后，该单词就会保存在生词本中。
5. 页面中相同的内容会自动变成黄色高亮。

例如选中：

```text
ephemeral
```

点击收藏后，页面中的 `ephemeral`、`Ephemeral` 等内容都会被高亮。

### 快速收藏按钮没有出现的常见原因

- 没有真正选中文字。
- 选择的内容超过了 200 个字符。
- 这个单词已经收藏过。
- 当前网页是 Chrome 内部页面。
- 插件刚安装或重新加载，但当前网页还没有刷新。
- 选中文字位于输入框、代码块或特殊网页组件中。

---

## 方法 2：右键菜单收藏

1. 在网页中选中一个单词或短语。
2. 点击鼠标右键。
3. 选择：

   ```text
   📖 添加到生词本
   ```

4. 收藏成功后，网页中的相同内容会自动高亮。

右键收藏不会弹出提示，但高亮出现就代表已经成功。

---

## 方法 3：键盘快捷键收藏

先选中文字，然后按：

### Windows / Linux

```text
Ctrl + Shift + S
```

### macOS

```text
Command + Shift + S
```

如果选中文字有效，插件会将其添加到生词本。

> 必须先选中文字。没有选中文字时，快捷键不会执行收藏操作。

---

## 方法 4：在插件弹窗中手动添加

1. 点击 Chrome 工具栏中的 WordBook 图标。
2. 在“输入新单词或短语”中输入内容。
3. 点击 **“添加”**，或者按回车键。

例如：

```text
machine learning
```

添加后，它会出现在生词列表中，并在网页中自动高亮。

### 添加限制

- 内容不能为空。
- 最多 200 个字符。
- 不区分大小写进行去重。

例如已经存在：

```text
Hello
```

再次添加：

```text
hello
```

会被判断为重复内容。

# 三、自动高亮功能

生词收藏后，插件会在网页正文中自动寻找并高亮它。

高亮样式为黄色：

```text
ephemeral
```

鼠标移动到高亮词上时，颜色会稍微加深。

## 高亮匹配规则

当前版本采用以下规则：

- 不区分大小写。
- 支持单词。
- 支持短语。
- 优先匹配更长的短语。
- 网页动态加载出来的新内容也会自动处理。
- 正则表达式中的特殊字符会按普通字符处理。

例如收藏：

```text
machine learning
```

页面中的：

```text
Machine Learning
```

也可以被匹配。

## 当前匹配属于“字符串匹配”

目前没有严格限制单词边界。

例如收藏：

```text
run
```

它也可能匹配：

```text
running
```

因为 `running` 中包含 `run`。

## 不会高亮的区域

为了避免破坏网页功能，以下区域通常不会被处理：

- 输入框
- 文本框
- 下拉菜单
- 代码块
- `<pre>`、`<code>`
- JavaScript 和 CSS
- SVG、数学公式
- 可编辑网页区域
- iframe 内部内容
- 插件自己的按钮和弹窗

## 短语限制

短语必须存在于同一个连续文本节点中。

例如：

```html
machine learning
```

可以正常匹配。

但如果网页写成：

```html
<b>machine</b> learning
```

因为中间跨越了 HTML 标签，当前版本可能无法将它识别为完整短语。

# 四、如何在网页中取消收藏

这是已经修复和重点优化的功能。

1. 点击网页中黄色高亮的单词。
2. 页面中会出现操作窗口：

   ```text
   📖 单词

   🗑️ 移除    ✖ 关闭
   ```

3. 点击 **“🗑️ 移除”**。
4. 删除成功后：
   - 这个单词会从生词本中删除。
   - 当前网页中的所有相同高亮会消失。
   - 其他打开网页中的高亮也会同步更新。

## 操作窗口的关闭方式

现在该窗口**不会自动快速消失**，可以通过以下方式关闭：

- 点击“✖ 关闭”
- 点击窗口以外的区域
- 按键盘 `Esc`
- 点击“移除”并成功删除

如果点击“移除”失败，按钮会显示：

```text
❌ 重试
```

可以重新尝试。

> “移除”是从整个生词本中删除，不是只取消当前网页上的一次高亮。

# 五、插件弹窗功能

点击工具栏中的 WordBook 图标，可以打开生词管理弹窗。

## 1. 查看生词数量

弹窗顶部会显示：

```text
15 个生词
```

生词列表默认按照收藏时间倒序排列，最近收藏的显示在前面。

---

## 2. 搜索生词

在搜索框输入部分文字即可搜索。

例如输入：

```text
learn
```

可以匹配：

```text
learning
machine learning
learn
```

搜索结果数量会显示为：

```text
15 个生词（匹配 3 个）
```

搜索只影响列表显示，不会删除或修改数据。

---

## 3. 编辑生词

每个生词右侧有一个编辑按钮：

```text
✏️
```

操作方法：

1. 点击编辑按钮。
2. 修改单词或短语。
3. 点击“保存”。

也可以使用：

- `Enter`：保存
- `Esc`：取消编辑

编辑成功后，网页中的旧高亮会消失，新内容会重新高亮。

例如将：

```text
colour
```

修改为：

```text
color
```

之后网页会改为高亮 `color`。

---

## 4. 删除单个生词

点击生词右侧的：

```text
🗑️
```

即可删除。

删除后：

- 生词从列表中消失。
- 所有打开网页中的对应高亮会同步消失。

当前单个删除不会再次弹出确认窗口，请注意不要误点。

---

## 5. 开启或关闭高亮

弹窗右上角有高亮开关。

### 显示：

```text
✅
```

表示高亮已启用。

### 显示：

```text
❌
```

表示高亮已停用。

关闭高亮后：

- 已收藏的生词不会被删除。
- 只是暂时不在网页中显示黄色高亮。
- 仍然可以继续收藏新单词。
- 再次启用后，网页会重新显示高亮。

这是一个全局开关，对所有网页生效。

# 六、导出和备份

建议定期导出生词，避免浏览器数据丢失。

1. 打开插件弹窗。
2. 点击：

   ```text
   📥 导出
   ```

3. 浏览器会下载类似下面的文件：

   ```text
   wordbook-2026-03-22. json
   ```

导出文件格式类似：

```json
{
  "exportTime": "2026-03-22 T10:30:00.000 Z",
  "version": "1.0",
  "words": [
    {
      "text": "ephemeral",
      "note": "",
      "createdAt": 1774175400000
    },
    {
      "text": "machine learning",
      "note": "",
      "createdAt": 1774175500000
    }
  ]
}
```

如果生词本为空，插件会提示没有数据可以导出。

---

# 七、导入生词

1. 打开插件弹窗。
2. 点击：

   ```text
   📤 导入
   ```

3. 选择之前导出的 `. json` 文件。
4. 插件会自动合并数据。

## 导入规则

- 不会覆盖原有生词。
- 按文字进行去重。
- 去重不区分大小写。
- 不合法的数据会被忽略。
- 超过 200 个字符的内容会被忽略。
- 同一个导入文件中的重复项只保留一条。

例如本地已经有：

```text
Hello
```

导入文件中存在：

```text
hello
```

它不会被重复导入。

除了插件导出的对象格式，也支持直接导入数组格式：

```json
[
  {
    "text": "ephemeral"
  },
  {
    "text": "machine learning"
  }
]
```

---

# 八、清空全部生词

1. 打开插件弹窗。
2. 点击：

   ```text
   🗑️ 清空全部
   ```

3. 浏览器会显示确认窗口。
4. 确认后，所有生词都会删除。

清空后：

- 所有网页中的高亮都会消失。
- 这个操作不能撤销。
- 建议清空前先导出备份。

# 九、数据保存位置和隐私

生词数据保存在：

```text
chrome. storage. local
```

也就是当前 Chrome 用户配置中的本地扩展存储。

## 数据特点

- 不会发送到外部服务器。
- 插件中没有联网请求。
- 不会自动上传生词。
- 不会自动同步到其他电脑。
- 卸载扩展可能会同时删除本地数据。

因此，重要生词建议定期导出。

## 插件权限说明

插件使用以下权限：

### `storage`

保存生词和高亮开关。

### `contextMenus`

提供右键“添加到生词本”菜单。

### `<all_urls>`

让插件能够在普通网页中读取文本并插入高亮。

它需要访问网页内容才能实现自动高亮，但当前代码不会把网页内容上传到服务器。

# 十、不能使用的网页

Chrome 不允许普通扩展在部分页面运行，例如：

```text
chrome://extensions/
chrome://settings/
chrome://history/
```

以及 Chrome Web Store 页面。

这是浏览器安全限制，不是插件故障。

## 本地 HTML 文件

如果想在 `file://` 本地文件中使用：

1. 打开 `chrome://extensions/`
2. 找到 WordBook
3. 点击“详细信息”
4. 开启“允许访问文件网址”
5. 刷新本地网页

## 无痕模式

如果想在无痕窗口中使用：

1. 打开插件“详细信息”
2. 开启“在无痕模式下启用”

# 十一、推荐使用流程

一个比较方便的日常流程是：

1. 阅读英文网页。
2. 遇到不认识的单词，用鼠标选中。
3. 点击“📖 收藏”。
4. 继续阅读。
5. 下次在其他网页遇到相同单词时，它会自动变成黄色。
6. 熟悉这个单词后，点击黄色高亮。
7. 选择“🗑️ 移除”。

这样插件就相当于一个跨网页的轻量生词本。

# 十二、常见问题

## 收藏后没有高亮

依次检查：

1. 插件右上角是否显示 `✅`。
2. 当前网页是否刷新过。
3. 当前页面是否属于 Chrome 内部页面。
4. 单词是否位于代码块、输入框或 iframe 中。
5. 插件是否已经重新加载。

---

## 取消收藏窗口还是快速消失

说明浏览器中可能还是旧版内容脚本。

处理方法：

1. 打开 `chrome://extensions/`
2. 找到 WordBook
3. 点击“重新加载”
4. 回到网页
5. 按 `Ctrl+R` 刷新网页

当前修复版本为：

```text
1.0.1
```

---

## 右键菜单没有出现

可以尝试：

1. 在 `chrome://extensions/` 重新加载插件。
2. 刷新网页。
3. 重新选中文字后点击右键。
4. 如果仍然没有，删除扩展后重新“加载已解压的扩展程序”。

---

## 快速收藏按钮不出现

可能是：

- 单词已收藏。
- 选中文字为空。
- 选中内容超过 200 字符。
- 当前网页禁止内容脚本。
- 选中文字位于特殊组件中。

可以改用右键菜单或插件弹窗添加。

---

## 修改或删除后其他网页没有立即更新

正常情况下会自动同步。如果没有：

1. 等待一秒。
2. 刷新对应网页。
3. 检查该网页是否在插件重新加载之前已经打开。

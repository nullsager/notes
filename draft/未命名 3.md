# AsyncLog 项目


大家好，我的项目是一个用 C++20 从零实现的高性能异步日志系统。

日志系统是几乎所有后端服务的基础设施。传统的同步日志每次写入都要等磁盘 I/O，会阻塞主线程。我的方案是异步架构：主线程只负责把消息放入一个无锁队列，后台线程批量取出写入文件，主线程几乎零等待。

这个项目最核心的组件是无锁队列，基于 Vyukov 的 MPMC 算法实现。它用 CAS 原子指令代替互斥锁，单次入队开销从微秒级降到了纳秒级。同时通过 Cache Line 对齐避免 False Sharing，用位掩码代替取模运算，进一步优化性能。

项目还充分利用了现代 C++ 特性：用可变参数模板和折叠表达式实现了类型安全的格式化引擎，支持花括号占位符；用 if constexpr 实现了编译期日志过滤，被禁用的日志级别不会生成任何代码，真正做到零开销；用 C++20 的 source_location 自动捕获每条日志的文件名和行号。

测试方面，项目包含 30 多个单元测试，覆盖格式化、无锁队列的多线程压力测试、以及日志器的集成测试，全部通过。性能测试显示，单线程入队吞吐量可达 40万条每秒。

以上就是我的项目介绍，谢谢大家。
